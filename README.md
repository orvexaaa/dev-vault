# 🔐 DevVault

**Your Personal Code Snippet Manager**

DevVault is a simple web application for storing, searching, and managing reusable code snippets in one place.

Built as a learning project to practice frontend web development using HTML, CSS, and JavaScript.

## ✨ Features

- 🔍 **Search Snippets** — Find snippets by title, description, or programming language.
- 📋 **Copy Code** — Copy code snippets to the clipboard with one click.
- ➕ **Add Snippets** — Create new snippets with a title, description, language, and code.
- 🗑️ **Delete Snippets** — Remove snippets you no longer need.
- 📱 **Responsive Design** — A layout that adapts to different screen sizes.
- 🌊 **Dark Ocean Theme** — A dark interface with blue accents.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/orvexaaa/dev-vault
   ```

2. Open the project folder.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
4. Start managing your code snippets!

## 📌 Current Limitations

- Snippets are stored in JavaScript memory and reset when the page is refreshed.
- No backend or database integration yet.
- Clipboard functionality requires browser clipboard permissions and a supported secure context.
